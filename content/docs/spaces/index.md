# Spaces

Construct organizes your workflow into specialized workspaces called **Spaces**. Each space is designed for a specific part of your development workflow, and they all work together seamlessly.

## Available Spaces

- [UI Designer](/docs/spaces/ui-designer) - Vector design editor powered by Fabric.js
- [Code Editor](/docs/spaces/code) - Full-featured editor powered by Monaco
- [Git](/docs/spaces/git) - Built-in version control
- [Terminal](/docs/spaces/terminal) - Integrated terminal emulator
- [AI Assistant](/docs/spaces/ai-assistant) - AI-powered project assistant
- [Tasks](/docs/spaces/tasks) - Kanban-style task management
- [Notes](/docs/spaces/notes) - Quick notes and reminders
- [Chat](/docs/spaces/chat) - Team communication
- [Architect](/docs/spaces/architect) - AI-powered project scaffolding
