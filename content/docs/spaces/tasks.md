# Tasks

The Tasks space provides Kanban-style project management, helping you organize work and track progress without leaving your development environment.

## Overview

The Tasks space offers:

- Kanban board view
- Task creation and management
- Drag-and-drop organization
- Filtering and search
- Calendar view
- Due dates and labels

## Getting Started

### Opening Tasks

Access the Tasks space from:

- The Spaces menu
- Keyboard shortcut: `Cmd/Ctrl + T`

### Board Overview

The default view shows:

- Columns representing stages
- Cards representing tasks
- Progress indicators
- Quick filters

## Kanban Board

### Default Columns

Standard columns include:

- **Backlog**: Future work items
- **To Do**: Ready to start
- **In Progress**: Currently working on
- **Review**: Awaiting feedback
- **Done**: Completed tasks

### Customizing Columns

Modify the board structure:

- **Add Column**: Click **+** at the end
- **Rename**: Double-click column header
- **Reorder**: Drag column headers
- **Delete**: Right-click and select Delete

### Column Limits

Set work-in-progress limits:

1. Click the column settings
2. Set a maximum card limit
3. Column highlights when limit is reached

## Tasks (Cards)

### Creating Tasks

Add new tasks:

1. Click **+ Add Task** in any column
2. Enter a title
3. Press `Enter` to save
4. Add details later as needed

### Task Details

Click a task to view/edit:

- **Title**: Main task description
- **Description**: Detailed notes (Markdown supported)
- **Due Date**: Deadline for completion
- **Labels**: Categorization tags
- **Assignee**: Who's responsible
- **Attachments**: Related files

### Moving Tasks

Reorganize tasks:

- **Drag and Drop**: Move between columns
- **Quick Move**: Right-click for column options
- **Keyboard**: Use arrow keys when selected

### Task Actions

Common operations:

- **Edit**: Click to open details
- **Duplicate**: Right-click > Duplicate
- **Archive**: Move to archive
- **Delete**: Right-click > Delete

## Labels

### Using Labels

Categorize tasks with labels:

- **Bug**: Issues to fix
- **Feature**: New functionality
- **Enhancement**: Improvements
- **Documentation**: Docs work

### Managing Labels

Create and edit labels:

1. Open task details
2. Click **Labels**
3. Create new or select existing
4. Customize colors

### Filtering by Label

View specific categories:

- Click label in filter bar
- Multiple labels filter together
- Clear filters to show all

## Due Dates

### Setting Dates

Add deadlines:

1. Open task details
2. Click **Due Date**
3. Select date from calendar
4. Optionally add time

### Overdue Indicators

Tasks show urgency:

- **Upcoming**: Yellow indicator
- **Due Today**: Orange indicator
- **Overdue**: Red indicator

## Calendar View

### Switching Views

Toggle to calendar:

- Click **Calendar** in view options
- Tasks appear on their due dates

### Calendar Navigation

Navigate the calendar:

- Use arrows to change months
- Click dates to see tasks
- Drag tasks to reschedule

## Filtering and Search

### Quick Filters

Use the filter bar:

- **My Tasks**: Only assigned to you
- **Due This Week**: Upcoming deadlines
- **By Label**: Filter by category

### Search

Find specific tasks:

1. Click the search icon
2. Type keywords
3. Results filter in real-time
4. Search includes title and description

### Advanced Filters

Combine multiple criteria:

- Label AND due date
- Assignee AND status
- Multiple labels together

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| New Task | `N` |
| Open Selected | `Enter` |
| Move Task | `Arrow Keys` |
| Delete Task | `Backspace` |
| Search | `Cmd/Ctrl + F` |
| Filter by Label | `L` |
| Switch View | `V` |
| Close Details | `Escape` |

## Integration

### With Other Spaces

Tasks connects with:

- **Git**: Link commits to tasks
- **Code**: Reference tasks in comments
- **AI**: Get help breaking down work

### Mentions

Reference tasks in other spaces:

- Use `#task-number` syntax
- Creates clickable links
- Shows task status

## Tips

1. **Keep Cards Small**: Break big tasks into subtasks
2. **Set WIP Limits**: Prevent overload
3. **Regular Reviews**: Move or archive stale tasks
4. **Use Labels Consistently**: Create a labeling system
5. **Update Status**: Move cards as work progresses
