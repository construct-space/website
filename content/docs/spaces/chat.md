# Chat

The Chat space provides built-in team communication, keeping project discussions alongside your code and design work.

## Overview

The Chat space offers:

- Chat rooms for team communication
- Member management
- AI integration
- Quick access with Ctrl+Ctrl
- Message history
- File sharing

## Getting Started

### Opening Chat

Access the Chat space from:

- The Spaces menu
- Quick access: Double-tap `Ctrl`
- Keyboard shortcut: `Cmd/Ctrl + Shift + C`

### Quick Access

The fastest way to chat:

1. Double-tap `Ctrl` key
2. Chat panel slides in
3. Start typing immediately
4. Press `Escape` to dismiss

## Rooms

### Default Rooms

Projects include standard rooms:

- **General**: Team-wide discussions
- **Development**: Technical topics
- **Design**: UI/UX discussions

### Creating Rooms

Add new rooms:

1. Click **+ New Room**
2. Enter room name
3. Set room type (public/private)
4. Add description
5. Click **Create**

### Room Types

Choose visibility:

- **Public**: Anyone on team can join
- **Private**: Invitation only
- **Direct Message**: One-on-one conversation

### Managing Rooms

Room administration:

- **Rename**: Click room settings
- **Archive**: Hide inactive rooms
- **Delete**: Remove permanently

## Messages

### Sending Messages

Communicate with your team:

1. Type in the message box
2. Press `Enter` to send
3. Use `Shift + Enter` for new lines

### Message Formatting

Format your messages:

- **Bold**: `**text**`
- *Italic*: `*text*`
- `Code`: `` `code` ``
- Code blocks: Triple backticks
- Links: Paste URLs (auto-link)
- Mentions: `@username`

### Code Snippets

Share code effectively:

```javascript
// Use triple backticks with language
function greet(name) {
  return `Hello, ${name}!`;
}
```

### Editing Messages

Modify sent messages:

1. Hover over your message
2. Click the edit icon
3. Make changes
4. Press `Enter` to save

### Deleting Messages

Remove messages:

1. Hover over your message
2. Click the delete icon
3. Confirm deletion

## Members

### Viewing Members

See who's in a room:

- Member list in sidebar
- Online/offline status
- Role indicators

### Inviting Members

Add team members:

1. Click room settings
2. Select **Invite Members**
3. Choose from team list
4. Send invitations

### Roles

Room permissions:

- **Owner**: Full control
- **Admin**: Can manage members
- **Member**: Can read and write
- **Guest**: Read-only access

## File Sharing

### Sharing Files

Send files in chat:

1. Click the attachment icon
2. Select file(s)
3. Add optional message
4. Send

### Drag and Drop

Quick file sharing:

- Drag files into the chat
- Preview appears
- Click send to share

### File Types

Supported formats:

- Images (preview inline)
- Documents
- Code files
- Design files

## AI Integration

### AI in Chat

Use AI assistance:

- Type `/ai` followed by your question
- AI responds in the chat
- Everyone can see and benefit

### Example Commands

```
/ai How do I center a div in CSS?
/ai Explain this error message
/ai Suggest improvements for this function
```

## Notifications

### Notification Settings

Control alerts:

- **All Messages**: Every new message
- **Mentions**: Only when @mentioned
- **None**: Silent mode

### Do Not Disturb

Focus time:

1. Click your status
2. Select **Do Not Disturb**
3. Set duration
4. Notifications paused

### Mentions

Get someone's attention:

- Type `@username`
- They receive a notification
- Use `@channel` for everyone

## Search

### Finding Messages

Search chat history:

1. Press `Cmd/Ctrl + F`
2. Enter search terms
3. Filter by room, person, date
4. Click to jump to message

### Filters

Narrow results:

- **From**: Specific person
- **In**: Specific room
- **Has**: Files, links, mentions
- **Date**: Time range

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Quick Access | `Ctrl + Ctrl` |
| Open Chat | `Cmd/Ctrl + Shift + C` |
| Send Message | `Enter` |
| New Line | `Shift + Enter` |
| Search | `Cmd/Ctrl + F` |
| Edit Last Message | `Up Arrow` |
| Mention | `@` |
| Emoji | `:emoji:` |
| Close Chat | `Escape` |

## Tips

1. **Use Threads**: Keep discussions organized
2. **Mention Sparingly**: Only when needed
3. **Share Context**: Include relevant links/files
4. **Code Formatting**: Use proper syntax highlighting
5. **Search First**: Check if question was answered
