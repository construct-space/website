# Notes

The Notes space provides a board of sticky notes for capturing ideas, reminders, and quick thoughts related to your project.

## Overview

The Notes space offers:

- Sticky notes on a flexible board
- Color customization
- Free positioning
- Team sharing
- Quick capture

## Getting Started

### Opening Notes

Access the Notes space from:

- The Spaces menu
- Quick capture: `Cmd/Ctrl + Shift + N`

### Board Overview

The notes board shows:

- All your sticky notes
- Color-coded categories
- Free-form arrangement
- Zoom and pan controls

## Creating Notes

### Quick Create

Add a note quickly:

1. Double-click on the board
2. Start typing
3. Click outside to finish

### From Menu

Create with options:

1. Click **+ New Note**
2. Choose a color
3. Enter content
4. Position on board

### Keyboard Shortcut

Fastest method:

- Press `N` to create at cursor
- Start typing immediately

## Note Content

### Text Formatting

Notes support basic formatting:

- **Bold**: `**text**`
- *Italic*: `*text*`
- Lists: Start line with `-`
- Links: URLs auto-link

### Checklist

Create todo items:

```
- [ ] Unchecked item
- [x] Checked item
```

Check items by clicking the checkbox.

## Customization

### Colors

Categorize with colors:

- **Yellow**: General notes
- **Blue**: Ideas
- **Green**: Complete/positive
- **Red**: Urgent/important
- **Purple**: Personal
- **Orange**: Warnings

Change color:

1. Right-click the note
2. Select **Color**
3. Choose new color

### Size

Resize notes:

- Drag corners to resize
- Double-click edge to auto-fit
- Minimum and maximum sizes apply

### Position

Arrange notes:

- Drag to move
- Snap to grid (optional)
- Align with other notes

## Organization

### Grouping

Organize related notes:

- Drag notes near each other
- Use color coding
- Create visual sections

### Stacking

Layer notes:

- Drag to overlap
- Right-click for layer order
- Bring to front/send to back

### Zooming

Navigate large boards:

- `Cmd/Ctrl + Scroll` to zoom
- `Cmd/Ctrl + 0` to fit all
- `Cmd/Ctrl + 1` for 100%

### Panning

Move around the board:

- `Space + Drag` to pan
- Two-finger scroll
- Click and drag background

## Sharing

### Team Notes

Share with team members:

1. Right-click the note
2. Select **Share**
3. Choose team or individuals
4. Set permissions (view/edit)

### Shared Indicators

Shared notes show:

- Collaboration icon
- Who's viewing
- Last edit info

## Search

### Finding Notes

Search your notes:

1. Press `Cmd/Ctrl + F`
2. Type search terms
3. Matching notes highlight
4. Navigate between matches

### Filters

Narrow down notes:

- By color
- By date created
- By shared status

## Export

### Single Note

Export individual notes:

1. Right-click the note
2. Select **Export**
3. Choose format (text, image)

### All Notes

Export entire board:

1. Click board menu
2. Select **Export All**
3. Choose format

## Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| New Note | `N` |
| Delete Note | `Backspace` |
| Edit Note | `Enter` |
| Save Note | `Cmd/Ctrl + Enter` |
| Duplicate | `Cmd/Ctrl + D` |
| Search | `Cmd/Ctrl + F` |
| Zoom In | `Cmd/Ctrl + +` |
| Zoom Out | `Cmd/Ctrl + -` |
| Fit All | `Cmd/Ctrl + 0` |
| Pan | `Space + Drag` |

## Integration

### Quick Capture

Capture from anywhere:

- Use global shortcut
- Note created with clipboard content
- Returns you to previous work

### With Tasks

Convert notes to tasks:

1. Right-click the note
2. Select **Create Task**
3. Note content becomes task

### With Code

Reference in code:

- Drag note into editor
- Creates comment with content
- Link back to note

## Tips

1. **Color System**: Establish consistent color meanings
2. **Board Sections**: Create visual areas for different topics
3. **Regular Cleanup**: Archive or delete old notes
4. **Quick Capture**: Use shortcuts for fast note-taking
5. **Link Notes**: Group related thoughts together
