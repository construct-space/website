# Quick Start

Get up and running with Construct in minutes. This guide walks you through creating your first project and exploring the core spaces.

## Creating Your First Project

1. **Launch Construct** and sign in to your account
2. Click **New Project** or press `Cmd+N` (macOS) / `Ctrl+N` (Windows/Linux)
3. Choose a project name and location
4. Select a template or start with a blank project

## Understanding Spaces

Construct organizes your workflow into **Spaces** - specialized workspaces that work together seamlessly. You can switch between spaces using the sidebar or keyboard shortcuts.

### Core Spaces

| Space | Description | Shortcut |
|-------|-------------|----------|
| UI Designer | Visual design editor | `Cmd+1` |
| Code | Monaco-powered editor | `Cmd+2` |
| Git | Version control | `Cmd+3` |
| Terminal | Integrated terminal | `Cmd+4` |
| AI Assistant | AI-powered help | `Cmd+5` |

## The UI Designer

The UI Designer is a powerful vector editor similar to Figma. Here's how to get started:

### Creating Shapes

Use the toolbar or keyboard shortcuts to create shapes:

- **Rectangle**: `R`
- **Ellipse**: `O`
- **Text**: `T`
- **Line**: `L`
- **Pen Tool**: `P`

### Selecting and Transforming

- Click to select objects
- Drag handles to resize
- Hold `Shift` while resizing to maintain aspect ratio
- Use `Cmd+G` to group selected objects

### Layers Panel

The Layers panel shows your document hierarchy:

- Drag to reorder layers
- Click the eye icon to toggle visibility
- Right-click for context menu options

### Properties Panel

When an object is selected, the Properties panel shows:

- **Transform**: Position, size, rotation
- **Fill**: Solid colors, gradients
- **Stroke**: Border color, width, style
- **Effects**: Shadows, blur

## Exporting Your Design

One of Construct's powerful features is code export. Select any object and export as:

- **SVG**: Vector graphics
- **PNG**: 1x, 2x, or 3x resolution
- **CSS**: Style properties
- **HTML**: Semantic markup
- **Vue SFC**: Single File Component
- **React JSX**: React component
- **Tailwind**: Utility classes

To export:

1. Select the object(s) you want to export
2. Press `Cmd+E` or right-click and select **Export**
3. Choose your format and options
4. Click **Export** or copy to clipboard

## Working with Code

Switch to the Code space to work on your project files:

1. Open the file browser on the left
2. Create or open files
3. Edit with full IntelliSense support
4. Run your project using the run controls

### Running Your Project

If your project has a run configuration:

1. Click the **Play** button in the toolbar
2. View output in the integrated terminal
3. Click **Stop** to terminate

## Version Control with Git

The Git space provides built-in version control:

### Basic Workflow

1. Make changes to your files
2. Open the Git space
3. Review changed files in the status panel
4. Stage files you want to commit
5. Enter a commit message
6. Click **Commit**

### Branches

- View and switch branches
- Create new branches for features
- Merge branches when ready

## AI Assistant

Get help with your project using the AI Assistant:

1. Open the AI space
2. Type your question or request
3. Get context-aware responses

The AI can help you:

- Explain code
- Suggest improvements
- Generate code snippets
- Debug issues
