# Installation

Construct is available for macOS, Windows, and Linux. Choose your platform below to get started.

## System Requirements

Before installing Construct, ensure your system meets the following requirements:

- **macOS**: macOS 11 (Big Sur) or later
- **Windows**: Windows 10 or later (64-bit)
- **Linux**: Ubuntu 20.04+ or equivalent

### Recommended Specifications

- 8GB RAM minimum (16GB recommended)
- 2GB available disk space
- Modern GPU for smooth UI Designer performance

## Download

Visit the [download page](/download) to get the latest version of Construct for your platform.

### macOS

1. Download the `.dmg` file
2. Open the downloaded file
3. Drag Construct to your Applications folder
4. Launch Construct from Applications or Spotlight

### Windows

1. Download the `.exe` installer
2. Run the installer and follow the prompts
3. Launch Construct from the Start Menu

### Linux

1. Download the `.AppImage` file
2. Make it executable: `chmod +x Construct-*.AppImage`
3. Run the AppImage: `./Construct-*.AppImage`

Alternatively, use the `.deb` package for Debian-based distributions:

```bash
sudo dpkg -i construct-*.deb
```

## First Launch

When you first launch Construct, you'll be guided through:

1. **Account Setup**: Sign in or create a Construct account
2. **License Activation**: Activate your license or start a free trial
3. **Preferences**: Configure your workspace preferences

## Updating Construct

Construct automatically checks for updates and notifies you when a new version is available. You can also manually check for updates:

1. Open Construct
2. Go to **Construct > Check for Updates** (macOS) or **Help > Check for Updates** (Windows/Linux)

## Uninstalling

### macOS

1. Quit Construct
2. Drag Construct from Applications to Trash
3. Optionally, remove preferences: `~/Library/Application Support/Construct`

### Windows

1. Open Settings > Apps
2. Find Construct and click Uninstall
3. Follow the uninstall prompts

### Linux

Remove the AppImage file, or if installed via `.deb`:

```bash
sudo dpkg -r construct
```

## Troubleshooting

### Construct won't start

- Ensure your system meets the minimum requirements
- Try reinstalling the application
- Check if your antivirus is blocking the application

### Graphics issues

- Update your graphics drivers
- Try running Construct with GPU acceleration disabled
